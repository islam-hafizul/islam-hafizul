## 🚀 Featured Projects

### 📝 Brammerly — Bangla Grammar & Spelling Checker

A natural language processing and machine learning project focused on Bangla spelling correction and grammar-error detection.

- Dataset processing: **30,001 articles and 565K+ sentences**.
- Reported spelling-correction performance: **85–90%**.
- Reported grammar-error detection accuracy: **70–80%**.
- Technologies: Python, TensorFlow, PyTorch, Hugging Face Transformers, BNLP, scikit-learn, Pandas, NumPy.
